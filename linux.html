Игры на Linux

Большинство Windows-игр отлично запускаются на Linux через Wine или Proton (Steam Play).

Установка через Wine

  1. Установите Wine (Debian / Ubuntu):
    sudo apt install wine
  2. Или включите Proton в Steam: Настройки → Steam Play → Включить Steam Play.
  3. Запустите установщик игры через Wine:
    wine Installer.exe
  4. Следуйте инструкциям установщика.
Подробно на сайте Wine

Проблемы и решения

  • Игра не запускается — доставьте зависимости через winetricks.
  • Нет звука — проверьте аудио-драйвер в winecfg.
  • Низкая производительность — попробуйте Proton Experimental.
